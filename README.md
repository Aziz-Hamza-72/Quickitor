# QuickiTor: Quick Image Converter - User Guide

Thank you for choosing QuickiTor! 

QuickiTor is a browser-based, privacy-first utility designed to make image conversion fast, local, and reliable. Because it runs entirely within your browser, your files are never uploaded to a server—ensuring your data stays on your machine.

---

## 🚀 Getting Started
1. Open the folder where you saved QuickiTor.
2. Locate the file named `index.html`.
3. Open `index.html` in your preferred web browser (Chrome, Firefox, Edge, etc.).
4. The tool is now ready to use!

---

## 🛠 How to Use QuickiTor

### 1. Select & Upload
- Choose the type of images you wish to upload.
- Drag and drop your images into the designated area or use the file picker.

### 2. Configure Output
You have two ways to convert your files:
- **Global Batch Conversion:** Select "Convert to All [Format]" to apply a single output format to every image in your current list.
- **Individual Conversion:** Use the **Control Card** (the interactive area displayed for each image). Here, you can preview the image and select a unique output format for that specific file.

### 3. Advanced SVG Handling
If you are converting an SVG that relies on external image files:
- QuickiTor will detect the dependency.
- Simply upload the required external photo with the original filename, and the tool will correctly process the SVG into your chosen extension.

### 4. Convert and Save
- Once your settings are configured, click the **"Convert and Download"** button.
- Enter a name for your ZIP folder when prompted.
- Wait a few moments while the browser processes the files (processing time depends on the number of images and your browser performance).
- The ZIP file will be downloaded automatically to your system.

*Note: You can also convert and download individual images by clicking the button on their respective Control Card.*
